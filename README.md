# React Slideshow

สไลด์โชว์บนเว็บด้วย React + Vite มี 2 โหมด คือแกลเลอรีสินค้าและงานนำเสนอ

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์ทดสอบ (ปกติที่ http://localhost:5173)
npm run build    # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist
```

ถ้าใช้ PowerShell บน Windows แล้วขึ้นว่า running scripts is disabled ให้พิมพ์ `npm.cmd` แทน `npm`

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/App.jsx` | โค้ด React ทั้งหมดในไฟล์เดียว: ข้อมูลสไลด์, ภาพ, หน้าตาสไลด์, Deck, App |
| `src/styles.css` | สีและรูปแบบทั้งหมด ปรับตามโหมดสว่าง/มืดของเครื่อง |
| `src/main.jsx` | จุดเริ่มต้นของแอป |
| `public/images/` | โฟลเดอร์วางรูปสินค้าของคุณ |

## ปรับแต่ง

ภายใน `src/App.jsx` แบ่งเป็น 5 ส่วนตามหัวข้อคอมเมนต์:

1. **ข้อมูลสไลด์**: แก้อาร์เรย์ `PRODUCTS` (สินค้า) และ `TALK` (งานนำเสนอ) และเวลาเล่นอัตโนมัติ `AUTO_MS`
2. **ภาพตัวอย่าง SVG**: ใช้เมื่อสินค้าไม่มีรูปจริง
3. **หน้าตาสไลด์**: `ProductSlide` และ `TalkSlide`
4. **Deck**: ปุ่ม จุด คีย์บอร์ด ปัดนิ้ว เล่นอัตโนมัติ เต็มจอ
5. **App**: สลับโหมด

### ใส่รูปสินค้าจริง

1. วางไฟล์ไว้ใน `public/images/` เช่น `public/images/dripper.jpg`
2. ในอาร์เรย์ `PRODUCTS` เพิ่มฟิลด์ `image` ให้สินค้านั้น

```js
{ id: 'dripper', name: 'Kōn 02', image: '/images/dripper.jpg', /* ...ฟิลด์เดิม */ }
```

สินค้าที่ไม่มี `image` จะแสดงภาพ SVG ตัวอย่างเหมือนเดิม รูปที่เป็นสี่เหลี่ยมจัตุรัสจะพอดีที่สุด ถ้าไม่อยากให้ถูกตัดขอบ เปลี่ยน `object-fit: cover` เป็น `contain` ใน `styles.css`
